## Подтверждённые ошибки

1. После получения свежего остатка 2 поиск другой партии возвращал в выбранную
   строку старый сохранённый остаток 10. Форма снова разрешала избыточное количество.
2. Общее обновление и ошибка чтения удаляли сведения о выбранной партии,
   хотя строки, количество и объект оставались в черновике.
3. Партия, исчезнувшая из обновлённого полного списка, могла использовать старое
   положительное количество из сохранённого выбора.
4. Безопасный повтор возврата очищал посторонний черновик пакетной выдачи.

До исправления упали четыре теста партий, затем отдельный тест повтора возврата.
Теперь сохранённый выбор обновляется последним принятым ответом сервера.
Общее обновление, ошибка источников и перезагрузка списка без фильтра снимают
подтверждение остатка; сведения о партии и ввод сохраняются. Новая выдача
запрещена, пока партия снова не получена через поиск/пагинацию. Повтор возврата
закрывает только возврат. Успешная выдача очищает только завершённый пакет и
его сохранённые варианты партий.

Поиск других материалов сохраняет последний подтверждённый остаток выбранной
партии, чтобы можно было собирать пакет через несколько поисков. Это не резерв
склада: другое действие может изменить остаток после чтения. Окончательную
проверку и атомарную запись выполняет существующий серверный обработчик.

| Действие | Проверенный результат |
| --- | --- |
| Остаток 10 → свежий ответ 2 → поиск другой партии | Сохраняется 2; прежние 5 отправить нельзя |
| Обновление под фильтром / ошибка 503 | Партия, объект, количество и основание сохранены; неизвестный остаток помечен и блокирует выдачу |
| Полный список больше не содержит выбранную партию | Старое положительное количество не разрешает отправку |
| Выбор с дальней страницы → обновление → загрузка страницы | Сохраняется ID; свежий ответ снова подтверждает остаток |
| Поздний ответ старого поиска | Не меняет последний принятый остаток |
| Ответ 401/403 | Сведения о партиях скрываются, отправка запрещена |
| Потерян ответ возврата → безопасный повтор | Черновик пакетной выдачи сохраняется |
| Потерян ответ выдачи после commit → повтор | Прежние ID и тело команды; нет дублей |
| Успешное проведение / повтор выдачи | Завершённая форма и её старые варианты партий очищены |
