# Возвраты денег и уменьшение суммы счёта

Локальный этап, не установлен на сервер. Миграция 0055 следует за 0054.
Новые действия по умолчанию отключены: нужны SUPPLIER_SETTLEMENTS_ENABLED=1
и существующие флаги журнала оплат. Интерфейс получает доступность от сервера.

## Поведение

- «Уменьшение суммы счёта» уменьшает обязательство, сохраняя исходную сумму.
  Денежного движения не создаёт; может показать переплату.
- «Возврат денег» регистрирует уже состоявшийся возврат и уменьшает чистую оплату.
  Не выполняет банковский перевод и не уменьшает обязательство автоматически.
- Каждую запись можно полностью сторнировать, не переписывая историю.
- Повтор запроса с тем же идентификатором возвращает прежний результат.
- Остаток долга и требование предоплаты учитывают скорректированное обязательство.
- Факты приёмки, складские количества и исходные стоимости партий не меняются.

## Ограничения перед выпуском

Поддерживаются самостоятельные счета без старого финансового зеркала накладной.
Если оплата распределена по партиям, возврат/корректировка блокируются; после
возврата/корректировки новые распределения также блокируются. Полная совместимость
с распределениями ещё не реализована. Корректировка НДС и автоматическая связь
финансового решения с претензией этим этапом не закрыты.

Остаются: поставки без первой оплаты, НДС и старые счета, полная проверка отчётов,
браузерный сценарий с тестовым API и проверяемый выпуск. Финансовый блок целиком
не считать завершённым. Рабочие данные и реальные письма не затрагивались.
