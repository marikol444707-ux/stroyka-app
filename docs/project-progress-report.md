## Подтверждённая ошибка и исправление

При отсутствии положительного плана сметы общий runtime подменял прогресс
отношением расходов к бюджету. Например, объект с сохранённым прогрессом 20%,
бюджетом 1000 и материалами стоимостью 1000 отображался как выполненный на 100%.
Расходы на материалы не подтверждают выполнение строительных работ.
Ветка сметы также допускала отрицательные значения, превышение 100% и NaN.

Теперь при отсутствии положительного конечного плана используется сохранённый
`project.progress`, независимо от расходов и бюджета. Для сметы сохранён прежний
источник `projectPlanDone`: сумма выполненного / план. Процент ограничен 0–100,
некорректные значения не доходят до UI. Для положительного выполнения меньше 1%
сохранено прежнее отображение 1%. Суммы смет, затрат и закрытия не изменяются.

Общий расчёт используется главной страницей, графиком объекта, кабинетом
технадзора и картой директора. Из runtime убрана ненужная зависимость от расходов.
