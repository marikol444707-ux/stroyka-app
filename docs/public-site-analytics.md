# Статистика публичного сайта

## Что считает

В CRM показываются просмотры публичных страниц за 30 дней, популярные страницы и UTM-метки. Отдельно в CRM остаётся статистика заявок с сайта и их переходов по этапам.

Это просмотры, а не уникальные люди: повторное открытие страницы считается повторно. Боты, предварительные просмотры мессенджеров и повторные запросы могут влиять на числа; использовать показатель как точное число клиентов нельзя.

Счётчик включён только на главной, контактах, возможностях, каталоге проектов, политике и условиях. В базе сохраняются дневные агрегаты по организации, пути страницы и ограниченным UTM-значениям. Он не записывает IP, cookie, User-Agent, referrer или индивидуальные события.

## Где смотреть

Откройте CRM в кабинете организации, к которой привязан публичный сайт. Блок «Просмотры сайта за 30 дней» находится над статистикой заявок. Доступ требует CRM-роли, данные ограничены организацией публичного сайта.

## Выпуск

В production-релиз входят миграция `0107_public_site_analytics`, backend endpoint, клиентский скрипт, CRM-блок и защищённый Nginx-маршрут. После установки релиза примените маршрут:

```bash
cd /var/www/stroyka-app
python3 scripts/ensure_public_site_analytics_nginx_route.py /etc/nginx/sites-enabled/stroyka
nginx -t && systemctl reload nginx
bash scripts/check-public-api-proxy.sh
```

После установки откройте публичную страницу и CRM организации сайта; значение просмотров должно увеличиться. Не проверяйте увеличение запросами нагрузки к рабочему счётчику.
