# Изоляция чтения счетов поставщиков

`GET /supplier-invoices` использует выбранную компанию и эффективную роль участника.
При сводке по всем компаниям права на объекты и пакеты работ считаются отдельно для
каждой компании. Поставщик видит счет только по своей группе поставщика и разрешённой
цепочке запроса/КП. Присоединённые поставка и складская накладная дополнительно
сверяются с компанией счёта.

Производственная проверка 02.10.2026:

- `49` счетов и `2` поставки проверены;
- все `51/51` строк имеют однозначную компанию и цепочку владения;
- неразрешённых, неоднозначных и несовпадающих строк нет;
- аудит выполнен в read-only транзакции с откатом, `writesAttempted=0`;
- запрос без авторизации к `/supplier-invoices` вернул `401`;
- `60` целевых тестов контекста компании, доступа поставщика и владения прошли.
