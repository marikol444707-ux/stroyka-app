# P8 — заказчики поставщика

Список строится из доступных адресных requests/offers, группировка по companyId,
никогда по названию. Общий каталог компаний не запрашивается. История включает
заявки, выбранные КП как заказы и документы с проверенной связью company/request/
offer/supplier. Контактные данные и реквизиты не расширяются относительно API.

Один полный снимок requests/offers/deliveries/invoices; загрузка и ошибка скрывают
прежние данные. Фильтр Все заказчики и карточка компании используют один снимок.
После отзыва доступа карточка исчезает, старое выбранное значение не раскрывает
данные. Переходы ведут к исходной заявке и существующим действиям. Финансовые
операции не меняются. Проверки: одинаковые названия разных компаний, чужие
документы, 2 заказчика, отзыв/ошибка, другой поставщик, mobile320, выпуск без миграции.
