# Остаток по актам бригады

Для договоров с `settlementVersion=2` стоимость выполненных работ и долг по
сохранённым актам — разные показатели. До создания акта выполнение не становится
долгом по актам. Штрафы учитываются ровно в сохранённом акте, без дополнительного
автоматического удержания 5% на экране бухгалтерии.

`GET /brigade-contracts` возвращает `settlementSummary` из `work_contract_acts`
и связанных `work_contract_act_payments` / `brigade_payments`. Стоимость, штрафы,
сумма после штрафов и оплаты суммируются отдельно. Остаток — сумма остатков актов.
Количество неподписанных актов позволяет показать требуемый документ даже при
нулевой денежной сумме. Даты фильтра предварительного нового акта на эти общие
показатели не влияют.

Запрос получает только пары договор/компания из существующей проверки доступа.
Читателям с ограничением по пакетам общие суммы всего договора не выдаются.
Отсутствующий или некорректный итог отображается как недоступный, без подстановки
стоимости работ. Наличие прежних несвязанных выплат или действующих старых актов
помечается `needsReconciliation`; такой итог не показывается как доказанный долг.
Проверки переходящего остатка при создании акта остаются в `require_reconciled`.

Карточка исполнителя, список бригад, бухгалтерские договоры и список актов
используют один frontend helper `brigadeBalance`. Итоговый долг по объекту
складывает долги отдельных договоров: аванс одному исполнителю не погашает долг
другому. Денежные значения показываются с копейками.

Прежние договоры сохраняют прежние правила расчёта. Изменение ничего не проводит:
не создаёт оплат, штрафов, актов или новых движений склада и не меняет данные.
