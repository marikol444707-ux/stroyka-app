# Просмотр документов поставщика

Маленькая ссылка PDF в КП заменена кнопкой «Открыть предложение». Счета в кабинете поставщика и заказах используют «Открыть счёт». PDF-вложения бухгалтерии используют тот же просмотрщик.

Документ открывается внутри приложения: на телефоне на весь экран, на компьютере в окне. Есть страницы, увеличение, скачивание оригинала и закрытие. Загрузка выполняется по нажатию с cookie и без постоянного кеша. Проверка прав остаётся на сервере. Отсутствующий файл, отказ в доступе, повреждённый PDF и ошибка загрузки отображаются в окне; можно повторить запрос. Смена компании закрывает просмотр и отменяет загрузку. Blob-ссылки и PDF-документ освобождаются при закрытии.

PDF.js загружается отдельным чанком по требованию. Worker упакован webpack в .js, чтобы nginx отдавал JavaScript с корректным типом. Файлы не уходят во внешние просмотрщики. Фото JPEG/PNG/WebP/GIF также отображаются; другие форматы не исполняются.

Проверки: полный frontend — 282 набора, 1754 теста; production build; реальный двухстраничный PDF в браузере, размеры 320/390/1280, листание, увеличение, скачивание оригинала, 404 и повторная загрузка. Тестовые данные этой проверки находятся только в локальном fixture; записей, писем, платежей и движений на рабочем сервере она не создаёт.

Очистка старых тестовых записей на рабочем сайте — отдельный следующий шаг: сначала проверить происхождение и связи точных ID, затем удалить штатными действиями приложения. По похожим названиям или суммам документы не удалять.
