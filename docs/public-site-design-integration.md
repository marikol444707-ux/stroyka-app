# Перенос согласованного оформления в рабочий сайт

Дата проверки: 10 ноября 2026. Статус: реализовано и проверено локально; на production не установлено.

## Что изменилось

- Первый экран и адаптивная навигация вынесены в `PublicSiteHero`. Вход в кабинет доступен и в мобильном меню.
- Каталог расположен перед калькулятором. Быстрый выбор задачи использует действующий выбор проекта.
- Контрастные панели стоимости; суммы не разрываются внутри числа на узких экранах.
- Четыре карточки контроля образуют заполненную сетку. Этапы строительства расположены компактно.
- Планировка, график оплаты, финансирование и демонстрационный паспорт раскрываются по запросу. Переходы автоматически раскрывают нужный раздел.
- Контакты и реквизиты берутся из `PUBLIC_SITE_OPERATOR`. Формы, согласия, загрузка файлов и API остаются рабочими компонентами приложения.
- Новый слой CSS ограничен `.public-site`. В код приложения не переносились заглушки API из прототипа.

## Проверки

- Production-сборка: `BUILD_PATH=build-design-review GENERATE_SOURCEMAP=false npm run build` — успешно.
- 50 тестов действий страницы и функций публичного сайта, затем 2 теста новой навигации — успешно.

Логи и снимки: `output/public-site-working-design/`. Локальный просмотр сборки: `http://127.0.0.1:8768/` пока запущен сервер. Без тестового перехвата API этот просмотр ожидает локальный backend; он не предназначен для подачи реальных заявок.

## Закрепление списка проектов — 10 ноября 2026

Исправлена причина пропавшего sticky: `overflow-x: hidden` у body создавал промежуточный контейнер прокрутки. На время показа публичной страницы html/body получают отдельный класс с `overflow-x: clip`; при выходе класс снимается. Высота списка ограничена высотой окна минус 40 px, нижние направления доступны внутренней прокруткой. Мобильный список сохраняет горизонтальную компоновку.

Сборка и 21 тест действий страницы прошли. В браузере на 1440×900 и 1024×600 список остаётся на отметке 20 px при прокрутке каталога; последний пункт доступен. На 390×844 горизонтального переполнения страницы нет. Снимок: `output/playwright/site-review/project-nav-sticky.png`. Исправление только в локальном просмотре, без публикации.

## Соответствие внутренних схем фасадам — 10 ноября 2026

Переработаны 18 этажных схем 11 вариантов домов: B1-02/03, FAM-02/03, H2-02, GAR-01/02/03 и TOWN-01/02/03. Компоновка учитывает видимые на иллюстрациях сторону гаража, выступы, террасы, этажность и остекление. Добавлена ориентация главного фасада. Для FAM-02 сохранён второй свет без вымышленного второго этажа.

Геометрические проверки охватывают все 33 схемы; отдельные проверки контролируют связи этажей и доступ к спальням.
