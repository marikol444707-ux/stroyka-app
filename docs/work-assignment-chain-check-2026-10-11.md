# Проверка выдачи и сдачи работ — 11.10.2026

Проверена версия кода после выпуска `e8b65aac1a65`.

На отдельной одноразовой PostgreSQL через настоящие HTTP-обработчики:

- Директор выдаёт одну из двух строк сметы выбранному исполнителю.
- Исполнитель получает её через тот же `/brigade-contract-items-all`,
  который загружает рабочий кабинет: точный объект, пакет, ключ строки,
  объём и цена исполнителя. Цена заказчика скрыта.
- Другой исполнитель и директор другой компании не получают чужую строку.
- Повтор выдачи сохраняет тот же наряд и не добавляет вторую позицию.
- Исполнитель отправляет два метра работы: результат поступает на проверку,
  сумма исполнителя составляет 120 рублей при цене 60 рублей за метр.
- После приёмки выполненный объём равен двум метрам, статус — «В работе».

Проверки: 14 интеграционных и 13 сценариев приёмки на PostgreSQL,
9 проверок маршрута назначения и 34 проверки интерфейса/команд отправки.
После добавления проверок загрузчика рабочего кабинета полный новый
сценарий отдельно прошёл повторно. Все запущенные сценарии прошли без пропусков.

Первоначально одноразовой схеме не хватало полей происхождения строки сметы.
Тест теперь применяет существующие функции подготовки этой схемы внутри
защищённой временной базы. Рабочая база и её схема не менялись.
Тестовые базы и сервер PostgreSQL удалены штатным launcher после проверки.

Граница проверки: подключение к браузеру пользователя не удалось
(`node:process` запрещён средой браузерного инструмента). Поэтому прохождение
в авторизованном рабочем кабинете production не подтверждено. Реальные
назначения, сдачи, приёмки, платежи и тестовые пользователи в production
не создавались. Этот выпуск добавляет только тест и отчёт; новый деплой
продуктового кода для него не требуется.
