## Реализованные функции сайта

Ниже перечислены функции, предусмотренные текущей версией сайта. Наличие кода не заменяет проверку полного production-сценария; непроверенные цепочки указаны в разделе «Что действительно осталось».

- Главная страница открывается без авторизации.
- Форма заявки создает лид в CRM и задачу директору.
- Форма партнёрской заявки создает лид в CRM на проверку и не выдает активный доступ автоматически.
- Блоки `Объекты`, `Контроль выполнения` и `Референсы` разделяют опубликованные объекты, примеры фиксации процессов и направления для будущих заявок. Фото в иллюстративном блоке нельзя выдавать за портфолио.
- В заявке фиксируются согласие на обработку персональных данных, страница, IP, User-Agent, referrer и UTM-метки.
- Есть `robots.txt`, `sitemap.xml`, `llms.txt`, PWA manifest, SEO/OG-мета и JSON-LD для поисковиков, мессенджеров и AI-агентов.
- Есть статические публичные страницы для индексации без входа в ERP: `/features.html`, `/project-catalog.html`, `/contacts.html`, `/privacy.html`, `/terms.html`.
- `npm run smoke:public-site` сверяет React-каталог, статический `/project-catalog.html` и локальные файлы проектных медиа, чтобы перед деплоем не проходили карточки без фасада, второго ракурса или планировки.
- Каждая карточка статического каталога должна вести на интерактивный проект: `/?project=H1-01#projects`, `/?project=B1-01#projects` и так далее.
- Статическая карточка проекта в `/project-catalog.html` должна сразу показывать площадь, этажность/формат, краткую планировку и состав визуалов, чтобы каталог был читаемым без React.
- `/project-catalog.json` отдает те же 15 направлений и 45 проектов в машинно-читаемом виде для AI-поиска, интеграций и автопроверок, включая статус `Проект-идея / пример для расчета`, площадь, этажность/формат, планировку, состав визуалов, полный `media[]` по каждому проекту и deep-link URL.

## Подготовлено локально, требуется выпуск

Локальная ветка `codex/public-site-lead-stats` опережает базовую ветку выпуска на 7 коммитов. В них входят статистика заявок сайта в CRM, надёжная очередь повторной отправки писем (миграция 0106 и системный таймер), точная маркировка иллюстративных фото, компактный мобильный выбор направления и документация. Эти коммиты ещё не установлены на production.

Статистика заявок — это метрики отправленных публичных форм по текущей организации: периоды 30/90 дней/всё время, статусы и UTM-источники. Это не аналитика посещений или конверсии всех посетителей.

## Что действительно осталось

### Нужно закрыть до платной рекламы

1. **Уведомление РКН.** Черновик сохранён, но не отправлен. РКН сообщил, что адресные значения формируются по ФИАС, а обращения нужно направлять через виджет «Госуслуги. Решаем вместе», не по email. Вопрос о недостающем районе Бирюлёво Западное фактически не решён. Уточнить через виджет, какое значение ФИАС выбрать для адреса IXcellerate, внести ответ в черновик и перед отправкой сверить поля с реальной обработкой.
2. **Выпуск 7 локальных коммитов и мобильная проверка.** После установки проверить каталог, калькулятор, мобильную панель и статистику в CRM. Для мобильной проверки использовать ширины 390 и 320 px.
3. **Проверка реальной заявки и письма.** Один раз отправить тестовую заявку с UTM и тестовым вложением, проверить лид в CRM, запись/статус письма в очереди и фактическое получение письма. Тестовую заявку после проверки пометить или удалить.
4. **Входящая почта.** Подтвердить, что обращения принимаются на `info@stroyka26.pro` и `privacy@stroyka26.pro`. Успешная SMTP-отправка с сайта этого не доказывает.
5. **Цены калькулятора.** Сверить 38 активных правил с утверждённым прайсом владельца. Не менять суммы на предположительные.
6. **Защита от DDoS.** Подтвердить настройки в панели Timeweb и проверить Nginx rate limits по `docs/ddos-and-ai-indexing.md`.

### Решения по содержимому и дополнительной проверке

- `/site/projects` возвращает пустой список. Можно добавить реальные объекты только с разрешёнными фотографиями и подтверждёнными данными; до этого галерея должна оставаться явно обозначенной как примеры.
- Сверить сроки хранения, список обработчиков и меры защиты с настройками/договором Timeweb. При необходимости передать юридические тексты юристу.
- TLS-сертификат при проверке 03.11.2026 действовал до 14.12.2026; проверить продление ближе к этой дате. DNS и редиректы повторно проверить при выпуске.

Платное продвижение отложено до завершения уведомления РКН, теста полного пути заявки и проверки защиты от DDoS. Банковские реквизиты на публичных страницах не размещать. Часы работы не указывать, пока владелец их не подтвердил.

systemctl daemon-reload
systemctl enable --now stroyka-public-site-lead-email.timer
systemctl is-active stroyka-public-site-lead-email.timer

## Деплой

```bash
cd /var/www/stroyka-app && git pull --ff-only && PYTHONPYCACHEPREFIX=/tmp/stroyka-pycache python3 -m py_compile backend/main.py && npm run build && npm run smoke:public-site && bash deploy.sh
```

Если добавлены новые backend routes, сначала обновить nginx routes и проверить, что они не отдают React `index.html`:

```bash
nginx -t && systemctl reload nginx
npm run smoke:public-api
```
