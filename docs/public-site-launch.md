## Перед рекламой и публикацией

### Статистика заявок с сайта

Подготовлено к выпуску: в CRM, над фильтрами входящих заявок, появится блок «Заявки с сайта». Он считает только обращения, отправленные через публичные формы, по организации текущего кабинета. Можно выбрать последние 30 дней, 90 дней или всё время; блок показывает заявки в работе, доведённые до договора/объекта, отказы и до пяти основных источников/UTM-кампаний. Заявки без меток объединяются под названием «Без UTM-метки».

Это статистика отправленных форм, а не посещений, просмотров или конверсии от всех посетителей. Для этих метрик понадобится отдельная система веб-аналитики с настройкой согласий и политики обработки данных.

## Проверка после деплоя

После выпуска очереди писем установить и включить системный таймер:

```bash
install -m 644 ops/systemd/stroyka-public-site-lead-email.service /etc/systemd/system/
install -m 644 ops/systemd/stroyka-public-site-lead-email.timer /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now stroyka-public-site-lead-email.timer
systemctl is-active stroyka-public-site-lead-email.timer
```

Проверить отправку и очередь:

```bash
systemctl start stroyka-public-site-lead-email.service
journalctl -u stroyka-public-site-lead-email.service -n 30 --no-pager
```

## Деплой

```bash
cd /var/www/stroyka-app && git pull --ff-only && PYTHONPYCACHEPREFIX=/tmp/stroyka-pycache python3 -m py_compile backend/main.py && npm run build && npm run smoke:public-site && bash deploy.sh
```

Если добавлены новые backend routes, сначала обновить nginx routes и проверить, что они не отдают React `index.html`:

```bash
nginx -t && systemctl reload nginx
npm run smoke:public-api
```
