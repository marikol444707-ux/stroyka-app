# Предупреждение о работах без помещения — 09.11.2026

Статус: локально подготовлено поверх установленного `477a6c7`.
Пакет исправляет только предупреждение в «Бухгалтерия → Закрытие».

## Поведение на практике

Подтверждённые работы без помещения не включаются в закрытие месяца.
Раньше строка с явным значением «Без помещения» исключалась молча: проверка
предупреждения учитывала только пустое значение. Теперь она учитывает и эту
пометку, включая пробелы и прежнее поле room_name.

Пользователь увидит существующее сообщение: «Не попадут в акт: 6 подтверждённых
строк без помещения или исполнительской суммы. Исправьте ЖПР перед закрытием месяца».
Нужно проверить записи в журнале производства работ и указать реальные помещения.
Когда исправленные данные поступят в экран, строки с положительной исполнительской
суммой войдут в расчёт. Автоматического назначения помещений, изменения статуса,
создания актов и выплат это исправление не добавляет.

Исправлена одна проверка: критерий отсутствующего помещения соответствует уже
существующему исключению строк из расчёта. Формулы, суммы, API, схема БД и права
доступа не менялись. Работы версии расчётов 2, другие месяцы и неподтверждённые
строки по-прежнему не попадают в это предупреждение.

## Установка и ограничения

Миграций нет, схема остаётся 0113. Перед переключением — проверка текущего HEAD,
feature flags, резерв текущих файлов/БД и полный запуск на восстановленной отдельной
базе. После переключения — backend, сохранность БД, хеши frontend и настоящий
экран директора с шестью строками за июль. Резерв/staging удалять только после
этих четырёх проверок. Откат к `477a6c7` возвращает прежние исходники/frontend,
не изменяя рабочую базу и не отменяя пользовательские операции.

Предупреждение остаётся общим за месяц, как раньше: подробного списка строк,
перехода к каждой записи и фильтрации предупреждения по объекту/исполнителю пакет
не добавляет. Исторические записи без помещения требуют проверки пользователем.
Распределение одного аванса по нескольким пакетам, разделение зарплатного аванса
и подотчёта на материалы, исторические выплаты без ID остаются отдельными задачами.
