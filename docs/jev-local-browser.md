# Jev с локальным браузером на Mac

Для macOS 12.7.6 отдельное приложение ChatGPT не требуется. Подтверждена схема:
изолированный Chrome на Mac → Playwright MCP 0.0.83 → SSH → исходная функция
`jev_ultrafast.model.choose` в существующем контейнере Timeweb → действие MCP.
Это отдельный демонстрационный исполнитель, а не запуск исходного `Agent.run`.

Агент запускает из этого checkout:

```bash
python3 scripts/jev_local_browser.py demo
```

Пользователь ставит задачу в чате, команды вручную ему выполнять не нужно.
Нужны установленный Chrome, Node/npm (`/usr/local/bin/npx`) и рабочий SSH-профиль
`stroyka-dev-agent` с доступом к контейнеру `stroyka-jev-control`. Ключ модели
используется только внутри существующего контейнера; он не копируется на Mac.
Файлы/настройки сервера и production «Стройки» этим запуском не изменяются.

Пока поддерживается только встроенная страница с одной кнопкой. Снимок её
видимого состояния передаётся на Timeweb, исходная модель Jev выбирает действие.
Исполнитель принимает только наблюдавшуюся кнопку либо `DONE`/`BLOCKED`, запрещает
повторное нажатие и проверяет отдельный видимый результат перед успехом.
Ограничены число шагов и время отдельных вызовов. При завершении/исключении
закрываются собственный браузер и процессы MCP, удаляются временные артефакты.

Для Авито добавлена только предварительная проверка:

```bash
python3 scripts/jev_local_browser.py avito
```

Авито использует отдельный постоянный профиль:
`~/.local/share/stroyka-jev/browser-profile` (права каталога 0700). Профиль
создаётся с нуля; личный профиль Chrome не подключается и не копируется.
`--user-data-dir` сохраняет настройки между запусками; демонстрация продолжает
использовать `--isolated`. Блокировка `profile.lock` разрешает только один запуск
этого контроллера с постоянным профилем. Второй завершается как `profile_busy`.
Закрытие браузера освобождает блокировку и удаляет временные артефакты, но
сохраняет профиль. Не удалять профиль и не читать его cookies/хранилища для
диагностики: проверять состояние через видимый интерфейс сайта.

Постоянный профиль пока не доказал исправление Авито. При первой проверке
навигация на сайт превысила 15 секунд; пустая страница в том же режиме открылась.
Открыто отдельное окно для ручного сравнения. Ручной результат и несколько
успешных поисковых запусков ещё нужны; само наличие профиля не является успехом.

Она открывает согласованный публичный поиск «кирпич б/у» в Ставропольском крае,
один раз ждёт обычную загрузку страницы и проверяет фактические URL, заголовок,
регион и наличие запроса. Потеря/подмена запроса, защитная проверка, ошибка 502 и
переход на другой сайт возвращают разные неуспешные статусы. Модель не вызывается,
задача не повторяется. Даже корректная поисковая страница не объявляется пятью
проверенными объявлениями. Подбор и проверка самих объявлений ещё не реализованы.

В ручной диагностике 19.10.2026 регион применился через интерфейс, однако отправка
поиска вернула главную без запроса; переход «Строительство стен» показал выдачу
«полу автомат». Причина этих ответов сайта не установлена. Ни рекомендации,
ни посторонняя выдача не приняты за результат поиска кирпича.

Не подтверждены: произвольные сайты, поиск пяти объявлений Авито, поля ввода Jev,
фильтры, расписание и автоматическое подключение инструментов к текущему чату
VS Code. Этот тест не обходит капчи и не использует личный профиль браузера.
Настройка MCP в Codex и этот исполнитель независимы: исполнитель может работать,
даже если текущий чат ещё не обнаружил новый MCP-сервер.

Проверка: `python3 -m unittest scripts.test_jev_local_browser`. Живой запуск на
Mac 19.10.2026 подтвердил `DONE`, два вызова модели и одно нажатие. Модульные
проверки дополнительно покрывают ложное завершение, ненаблюдавшуюся/неоднозначную
кнопку, запрет повторного нажатия, завершение при сбое модели и скрытие stderr.
