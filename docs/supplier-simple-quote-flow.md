# Обычный процесс закупки

Решение пользователя от 09.10.2026: поставщик сам отвечает, может ли поставить
товар, своим КП. Отдельное подтверждение возможности поставки директором убрано
из карточки заявки, включая случаи включённого старого флага.

Процесс: заявка → ответы поставщиков → сравнение КП → выбор пользователем.
Сравнение цен/условий и проверка соответствия товара заявке остаются. Отдельных
автоматических отправок или решений это изменение не добавляет.

Исторические подтверждения и их серверное хранение не удаляются. Прежняя
незавершённая проверка создания/отзыва через обычную карточку больше не является
требованием её приёмки. Уборка тестовых данных остаётся отложенной пользователем.

Регрессия проверяет отсутствие панели даже с включённым флагом, наличие КП и
отсутствие сетевых запросов подтверждения при открытии заявки.
