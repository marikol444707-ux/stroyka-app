# Изображения публичного сайта

## Оформление планировок — 10 ноября 2026

33 сгенерированные предпроектные схемы получили архитектурную подачу: белый фон, штриховку стен, оконные проёмы, двери с дугами открывания, мебель и отдельную экспликацию помещений. Есть крупная векторная версия. Девять импортированных исходных чертежей не изменены. Геометрия схем остаётся концептуальной; соответствие конструктиву и фасадам не подтверждено, размеры и проёмы требуют проектирования. B2-02 остаётся без неподтверждённых планировок.

Рисунок строит `scripts/public-plan-architectural-renderer.js`. Исправлены пересечения прямоугольников помещений в B1-02, APT-03 и FIN-02; двери соединяют соседние комнаты с приоритетом выхода в холл. Это улучшение эскизной геометрии, не архитектурная экспертиза. Проверка `node --test scripts/test-public-plan-architecture.js` контролирует отсутствие пересечений, связность комнат и границы внутренних/внешних стен. FIN-03 содержит два отдельных этажа на одном листе.

Генератор: `node scripts/generate-public-plan-presentation.js`. Он использует явный список кодов, чтобы не перезаписывать исходные чертежи, и создаёт PNG, `*-diagram.svg`, `*-sheet.svg` и `src/features/public-site/projectPlanPresentation.json`. Старый генератор без ограничения кодов для этой задачи запускать нельзя: он затрагивает также импортированные материалы.

Дополнительная детализация: `scripts/public-plan-fixtures.js` рисует кровати, диваны, сантехнику, лестницы и автомобиль в виде сверху. Добавлены оконные переплёты, раздвижные выходы и гаражные ворота. Во вторых этажах H2-02, GAR-01–03 и TOWN-01–03 добавлен коридор с изменением эскизной геометрии; тест проверяет выходы спален в общую зону без прохода через другую спальню. Эти изменения не подтверждают соответствие этажей друг другу, фасадам или площади карточки; размерные цепочки намеренно не заявлены.

React показывает рисунок и список помещений раздельно; на узком экране список расположен снизу. PNG используется в статическом каталоге, полный SVG открывается по ссылке «Открыть крупно». Статическая проверка допускает только SVG из манифеста и отклоняет активное содержимое и ссылки внутри SVG.

## Строительные иллюстрации — 10 ноября 2026

`illustrations/generated/project-dossier.jpg` создан встроенным imagegen для карточки «История вашего объекта» и заменяет CSS-рисунок листа паспорта. Это синтетическая иллюстрация: папка с чертежами, фото этапов и планшет. Не является фото выполненного объекта. PNG сохранён в каталоге генератора, JPEG для сайта — в `public/site-assets/illustrations/generated/`. Промпт:

`illustrations/generated/materials-delivery.jpg` и `illustrations/generated/site-supervision.jpg` созданы через imagegen для карточек материалов и журнала работ. Это синтетические иллюстрации, не фотографии выполненных объектов компании. Они заменяют неподходящие лабораторные фотографии. Файлы размещены локально; внешних запросов при показе нет.

Из опубликованного каталога убраны H2-03 и B2-03 с повторяющимися фасадами. Осталось 43 карточки; проверка статического каталога контролирует совпадения файлов фасадов по SHA-256. У B2-02 сняты неподтверждённые схемы этажей, оставлены два ракурса концепции.

Иллюстрации в маркетинговых карточках загружаются с домена сайта из `public/site-assets/illustrations/unsplash/`. Внешние запросы браузера к Unsplash не нужны. Это лицензированные иллюстративные изображения, а не подтверждение выполненных работ СтройКа.
