# Сообщения владельцу о новой заявке

Когда с сайта, из Max или из CRM (если заявку отметили как рекламную) появляется новая заявка, программа кладёт сообщение в очередь мессенджера. Сама заявка при этом не ждёт Telegram или Max: если мессенджер недоступен, заявка всё равно сохраняется.

Сообщение на русском: «Новая заявка», имя, телефон, что нужно, адрес, источник и ссылка на карточку в CRM.

Очередь разбирает уже включённый таймер `stroyka-max-dispatch.timer`. Он запускается примерно раз в минуту. Поэтому сообщение приходит не в ту же секунду, а в течение около одной минуты. Отдельный новый таймер не нужен. Этот таймер ходит на сервер с токеном Max, поэтому `MAX_BOT_API_TOKEN` или `MAX_WEBHOOK_SECRET` на сервере должен быть задан, даже если писать нужно только в Telegram.

Письмо на почту, как и раньше, может прийти отдельно и позже. Это другое уведомление.

## Что прописать на сервере

Имена переменных, без значений:

- `LEAD_NOTIFY_TELEGRAM_CHAT_ID` — куда писать в Telegram. Если пусто, Telegram молчит.
- `LEAD_NOTIFY_MAX_CHAT_ID` — куда писать в Max. Если пусто, Max молчит.
- `LEAD_NOTIFY_COMPANY_ID` — необязательно. Если указан номер компании, сообщения уходят только по заявкам этой компании.
- `TELEGRAM_BOT_API_TOKEN` — уже существующий токен бота Telegram. Нужен, чтобы очередь реально отправила сообщение.
- `MAX_BOT_API_TOKEN` — уже существующий токен бота Max. Нужен и для отправки в Max, и чтобы минутный таймер вообще мог разобрать очередь.
- `APP_PUBLIC_URL` — адрес сайта в ссылке. Если не задан, ссылка ведёт на `https://stroyka26.pro`.

Пока достаточно одного чата владельца. В строке очереди всё равно записывается компания заявки, чтобы чужая компания не смешивалась с этой.

Значения токенов в документы, чаты и снимки экрана не копировать.

## Как узнать свой Telegram chat id

1. В Telegram откройте бота СтройКа, тот самый, чей токен уже лежит на сервере в `TELEGRAM_BOT_API_TOKEN`, и напишите ему «привет».
2. На сервере, в каталоге программы, выполните команду. Она сама подставит токен из настройки и не требует вписывать его в команду руками:

```bash
curl -sS "https://api.telegram.org/bot${TELEGRAM_BOT_API_TOKEN}/getUpdates"
```

3. В ответе найдите `"chat":{"id":` и скопируйте только число. Для группы оно может начинаться с минуса. Это число и есть `LEAD_NOTIFY_TELEGRAM_CHAT_ID`.
4. Весь ответ команды никому не пересылайте: в нём есть текст переписки. Сам токен бота в ответ не попадает, но и его показывать не нужно.

## Как узнать chat id в Max

Напишите боту Max личное сообщение. Идентификатор этого диалога — тот же `chat_id`, который бот уже использует для ответов. Его можно взять из входящего обновления бота. Это число или строка для `LEAD_NOTIFY_MAX_CHAT_ID`. Токен Max при этом никуда не копируйте.

## После сохранения настроек

Перезапустите службу сайта, чтобы она увидела новые переменные. Таймер `stroyka-max-dispatch.timer` должен быть активен. Проверка: отправьте тестовую заявку со ссылкой из `docs/ad-source-links.md` и в течение минуты посмотрите сообщение в Telegram или Max.
