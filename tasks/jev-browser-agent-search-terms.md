# Словарь поиска строительных заказов

Применять наборы отдельно по типам источника: закупочные извещения, частные заявки и субподряд. Регион по умолчанию: Ставропольский край; географические варианты: Ставрополь, Михайловск, Пятигорск, Кисловодск, Ессентуки, Минеральные Воды, Невинномысск, Георгиевск, Будённовск, Изобильный, Ипатово, Светлоград, Благодарный, район/округ и сёла края.

## 8. Исключения и понижение релевантности

Для поиска именно подрядных работ понижать/исключать: «ищу работу», «резюме», «вакансия» без явного заказа/объёма; объявления исполнителей «выполним», «оказываем услуги»; закупка только материала/оборудования без монтажа; ремонт автомобилей/техники; бытовые услуги вне стройки; завершённые тендеры; планы закупок без опубликованного извещения. Не исключать вакансию автоматически, если в тексте есть отдельное предложение субподряда или конкретный объём работ.

## 9. Правила запроса

- Не отправлять одну огромную строку поиска: комбинировать регион + группа работ + тип объекта.
- Для ЕИС сначала фильтровать край и активный срок подачи, затем ключевые слова/ОКПД2 и тип закупки.
- Для частных заявок искать фразы намерения заказчика («нужно», «ищу бригаду», «требуется подрядчик») и проверять дату публикации.
- Для каждого результата сохранять исходную формулировку и ссылку; ИИ может классифицировать и ранжировать, но не должен приписывать отсутствующие бюджет, сроки или объёмы.
- Дедуплицировать по ID закупки или URL; если ID нет — по нормализованным заголовку, региону, заказчику и дате.
