# Telegram: заказы на отделку и ремонт

Подтверждено пользователем: подготовить процесс, тема — отделка и ремонт.
Источники и география ещё не заданы. Не считать Ставропольский край заданным
фильтром только по предыдущему поиску закупок. Не включать расписание до проверки
конкретных источников и авторизации.

## Первая версия

1. Офлайн обработчик стандартной JSON-выгрузки Telegram Desktop.
2. Одноразовый сбор новых сообщений через отдельную уже авторизованную Telethon
   сессию только из явно перечисленных каналов/групп. Никаких личных диалогов,
   вступлений, отправок, загрузки вложений или доступа к ключам Jev/ИИ.
3. Три результата: вероятный заказ, требует просмотра, предложение услуг.
   Объявления о продаже материалов не считать заказом. Правила эвристические,
   полноту и актуальность заказа не гарантируют.
4. Точные повторы текста группировать с сохранением всех ссылок. Оригинальный
   текст, дата и источник обязательны. Бюджет не выдумывать.
5. Приватная HTML/JSON сводка. Cursor сохранять атомарно только после успешной
   записи отчёта. Ошибка отдельного источника не продвигает его cursor.
   Сбор ограничен порцией; при переполнении дочитывать старые новые сообщения
   перед более свежими. FloodWait возвращать как retry_after, без обхода.

Данные не отправляются в LLM: по правилам Telegram использование контента в ИИ
требует отдельного согласия соответствующих пользователей.
https://telegram.org/tos/content-licensing

## Проверка

`python3 -m unittest scripts.test_jev_telegram -v`

Проверить заказы/рекламу/неопределённость, Unicode/дубли, повреждённую выгрузку,
HTML injection, отсутствие источников, частичную ошибку, порционное чтение,
неавторизованную сессию и отсутствие отправляющих методов.
