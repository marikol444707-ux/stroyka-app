# Объединение дублей в выбранной организации

Пользователь подтвердил: карточки «Эвереста» и «Сатурна» появились разными путями
и относятся к тем же поставщикам. Это основание для явного выбора карточек,
не для автоматического предоставления доступа по похожему названию.

Первый проверяемый этап: администратор платформы выбирает дубль без кабинета,
ищет основную карточку в той же организации и проверяет последствия.
Если обе карточки без кабинета, подтверждение с основанием объединяет только
связи каталога. Права кабинетов и оригиналы документов не меняются.
Если основная карточка с кабинетом, используется существующий план открытия
истории с полной проверкой принадлежности; этот этап не обходит проверку ИНН.

Сервер: только свежие активные полномочия администратора, активная компания,
включённый PARTICIPANT_HISTORY_MERGE_ENABLED. Блокируются другая компания,
владелец/команда у дубля, конфликт известных реквизитов и изменившаяся проверка.
Сохранить IDs документов, снимки реквизитов и суммы оплат, записать аудит.
Новые объединения не должны образовывать цепочки. Повторное подтверждение
не меняет данные. Поиск не ограничивается текущей страницей списка.

Проверки: успешное объединение без изменения исходного счёта; отказ для
кабинета, чужой компании, конфликта ИНН, устаревшего просмотра, отключённого
флага и отозванного администратора. Интерфейс: выбор/поиск, явное подтверждение,
основание, ошибки и повторная проверка, закрытие при смене организации.

Пользователь дополнительно подтвердил по документам одинаковый ИНН для
карточки «Сатурн» и кабинета. Добавлено отдельное подтверждаемое заполнение
пустого ИНН основной карточки из дубля: только администратор, свежий просмотр,
основание и аудит. Существующий ИНН не перезаписывается; кабинет с другими
организациями или другой кабинет с этим ИНН требуют отдельной проверки.
Заполнение профиля не открывает историю. После него обязательно создаётся
новый полный план исторического объединения; старые документы не меняются.
Никакие реальные записи на сервере этим этапом автоматически не изменяются.
