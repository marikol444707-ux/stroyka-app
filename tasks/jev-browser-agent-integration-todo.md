**Текущий предел автоматизации:** кодовый sender готов, но автоматическая передача не включится, пока выпуск не настроит `JEV_OPPORTUNITY_INGEST_KEY` и `JEV_OPPORTUNITY_COMPANY_ID` на backend, а такой же ключ не будет безопасно добавлен в окружение JEV. После этого запуск отчёта и push выполняются одной командой через stdin; расписание пока выключено.

## Итоговая проверка

- [ ] Один источник проходит путь источник → сбор → дедупликация → проверка → карточка в Стройке.
- [ ] Повторный запуск не плодит дубли.
- [ ] Источники с блокировкой не обходятся и явно показывают статус.
- [ ] Любой срок/цена в тендере ведёт к официальному извещению ЕИС/ЭТП.
