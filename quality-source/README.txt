СтройКа — контрольный ракурс гостиной, living-quality-v28

Отдельная рабочая 3D-сцена для оценки качества. Основной прототип v26 и production не заменены. В этой сцене фиксированный дневной свет и небольшой поворот камеры; разборка дома, материалы, стили и полная прогулка остаются в основном прототипе и ещё не перенесены в новый уровень изображения.

Что изменено
Диван заменён авторской моделью GlamVelvetSofa — Eric Chadwick / Wayfair LLC, CC BY 4.0. Сохранены исходная изогнутая геометрия, normal/AO и sheen. Выбран серый вариант, изменены оттенок, равномерный размер и размещение. Ширина около 2.17 м; это не прежний диван с теми же габаритами. Добавлены замкнутые мягкие подушки с кантом. У них освещение PBR в реальном времени, чтобы маленькие островки карты не давали ступенчатых артефактов.
Стол получил слабую минералогическую фактуру и микрорельеф камня, деревянное рифление опоры; на нём открытая керамическая чаша и книга. Стыки деревянного пола уменьшены с 3 до 0.7 мм. Прежняя грубая мебель террасы сохранена в геометрии для прослеживаемости, но скрыта и в браузере, и при расчёте света этого ракурса.
Панорама за окнами теперь 4096×2048. Это SDR-слой официального UltraHDR JPEG, без декодирования gain map. Окружение Poly Haven — условный вид, не реальный участок заказчика. Для освещения используется исходный HDR 1K. Стекло показано тонким прозрачным слоем, это визуальное приближение, не точная симуляция стеклопакета.
Камера снижена до фотографического ракурса [3.65, 1.40, 1.65], цель [4.8, .65, 3.48]. comparison-before.png показывает старую сцену v27, переснятую с этой же позиции; comparison-after.png — новую. Сравнение не выдаётся за прежний опубликованный кадр.

Свет
Полная цепочка Blender 4.3.2 Cycles CPU → diffuse direct+indirect без базового цвета → Open Image Denoise 2.3.3 RTLightmap → линейный EXR реально выполнена для финальных ассетов: 2048², 96 сэмплов. Проверка rebuild-check.json содержит хеши конечных GLB/EXR. UV1 для световой карты, UV0 для базовых фактур. В Three для EXR flipY=true; три мягких источника добавляют объём/отражения. Новая мебель и материалы не означают достижения фотографического эталона.

Проверки
check-quality.mjs проверяет исходные строительные точки 15 групп: 92528 образцов, 0 пропавших с допуском 0.4 мм; исходные навигационные файлы сохранены. Новая мебель находится над прежними препятствиями. GLB: 51 часть, 178811 вершин; 3 старые части террасы скрыты. Проверены UV1, 567 положений камеры, сохранение 3118 образцов авторского дивана и его карт/лицензии. EXR 2048² имеет конечные положительные значения HDR.
check-browser.cjs проверяет реальную загрузку касанием, отсутствие тяжёлой сцены до кнопки, мышь/касание, точный возврат камеры, 5 ширин, закрытие, реальную ошибку при блокировке EXR и успешную повторную загрузку. Результат browser-check.log. Скрипт не заменяет физический iPhone/Safari и замеры FPS — они ещё не выполнены.
Кадры living-*-final.png и comparison-*.png сняты в Chromium/SwiftShader. Это не Image Gen и не офлайн-рендер Blender. living-quality.gif/mp4 — монтаж настоящих кадров, не непрерывная запись анимации и не тест FPS. Визуальная приёмка пользователем остаётся открытой.

Запуск локально
npm install
npm run build
python3 -m http.server 8822 --bind 127.0.0.1
Открыть http://127.0.0.1:8822/index.html на том же компьютере.

Повторное создание ассетов
Нужны Blender 4.3.2 с Cycles CPU и внешний Open Image Denoise 2.3.3. Официальный URL/хеш зависимости в dependency-record.json; исполняемые файлы не входят в пакет. Исходные BLEND, HDR и авторский GLB включены.
python3 rebuild.py --oidn /путь/к/oidnDenoise
Полная финальная конфигурация по умолчанию — 2048²/96. Для быстрого технического теста можно задать --output /другая/папка --atlas 256 --samples 2; такой результат не годится для оценки изображения.
Сборка страницы: npm run build. Проверка ассетов: node check-quality.mjs. Проверка браузера при запущенном HTTP: python3 run-browser.py check-browser.cjs (нужны Chromium и FFmpeg).
