Разработка публичного сайта v32 — сохранение выбора проекта

Основа — полный прототип house-lab-v26, а не ограниченная студия гостиной v31. Новая функция сохраняет семью, пожелания, участок/город, выбранные стены/кровлю/фасад и стиль интерьера. Сохранение только по явной кнопке, без автоматической записи и автоматического применения после перезагрузки. Восстановление — отдельная команда. Удаление убирает копию из localStorage, текущая работа на странице остаётся. Хранилище доступно скриптам того же origin: это не шифрование и не учётная запись. На общем устройстве удалить черновик. Переезд на другой origin/браузер не переносит черновик. Только один черновик Дома01; явное сохранение заменяет предыдущий.
Добавлено скачивание текущего канонического описания UTF-8 .txt, содержимое совпадает с реальным выбором, без имитации отправки. Реальные контакты, доставка обращения, база цен и публичный хостинг пока не подключены. Нет заявки в CRM/почте. Модель загружать для этих функций не нужно. Стиль из черновика применяется и до загрузки 3D; после старта прежняя функция стилей использует восстановленный id.
normalizeDraft проверяет версию/проект/структуру/известные материалы/стиль, контекст проходит существующую нормализацию. Битый или несовместимый черновик не изменяет текущую работу. Ошибки localStorage сообщаются явно. Нельзя называть сохранение синхронизацией с сервером. Цены и одобрение проекта этим не появляются.
Проверки: node check-project-draft.mjs (roundtrip, ноль детей, открытые решения, несовместимость, плохой JSON/размер, удаление, ошибки хранилища); существующий check-project-discussion.mjs; Chromium check-draft-browser.cjs (настоящая перезагрузка, ручное восстановление/стиль без3D, повреждение/квота, удаление, настоящий скачанный файл с текущими данными, mobilewidth320/390/700, безGLB/безcanvas); прежний check-discussion-browser.cjs (копирование в реальный clipboard/readback, синхронизация семейной формы/материалов/обсуждения, открытые вопросы, layout/сбросы). Пропусков вместо успешных проверок нет. Физический iPhone/Safari и рабочий сервер не проверялись этой итерацией.
Локальный запуск: npm install; npm run bundle; python3 build_viewer.py; python3 -m http.server 8826 --bind 127.0.0.1. Открыть http://127.0.0.1:8826/index.html. Браузерный тест: python3 run-browser.py check-draft-browser.cjs. Нужны Chromium/FFmpeg. Сборка сохраняет полный исходный дом/разборку/материалы/план/прогулку. Пакет — прототип публичного сайта, не установщик production и не объединённое обновление приложения.
Демо-ветка demo/house-06, без main/PR/production deployment. Интерактивного публичного веб-адреса пока нет. Визуальные студии гостиной остаются отдельными исследованиями, их новый свет не переносился безусловно во все режимы дома.

Изменения
Вокруг той же модели добавлено предлагаемое озеленение: шесть деревьев, восемь кустовых групп и газон с процедурной фактурой. Кроны из отдельных изогнутых листьев, а не геометрических шаров. Всего пять новых групп отрисовки: газон, ветви и три InstancedMesh листвы. Новых источников света нет, движение растений не рассчитывается. Дополнительные изображения/библиотеки из внешней сети не подгружаются. Виды из окон используют настоящее окружение сцены, не фон-картинку.
В планировке, разборке, кровле, разрезе, строительной истории и учебных схемах озеленение скрыто. Выход из учебной схемы восстанавливает видимость в соответствии с прежним режимом. Растения находятся вне дома и террасы. Это художественная идея, не утверждённый ландшафтный проект или подбор видов растений для участка.
Две существующие подушки дивана стали мягче и прямоугольнее, получили ткань для каждого из трёх интерьеров. Для этого временно клонируется один объединённый sage-mesh: из 458 вершин двух подушек координаты меняются у 374, остальные вершины и их нормали сохраняются. Положения мебели, размеры и навигация сохраняются; новые объекты в проходах не появляются. Перед освобождением сцены исходные геометрия и материал восстанавливаются. Остальные части этого mesh (кухня, стулья, спальни, кабинет) не получают ткань подушек.
Интерьерные ракурсы используют вертикальное поле зрения 54° и zoom 1, отдельно от внешнего обзора и 68° прогулки. Так виднее вся комната; на телефоне больше не применяется масштаб внешнего обзора к интерьеру.
Повороты взгляда в прогулке сглаживаются коротким экспоненциальным фильтром, одинаковым для разной частоты кадров. Координаты человека не интерполируются: они по-прежнему проходят через старый проверенный collision solver. Reduced motion отключает сглаживание; выход из прогулки, blur и pointercancel сбрасывают ожидающий поворот. Возобновление сохраняет фактическую позу. Вход по кнопке комнаты остаётся быстрым переходом, не анимированным маршрутом через стены.
Семья, материалы, темы разговора и общий текст пожеланий работают как прежде. На телефоне WebGL и модель открываются по кнопке. Широкие экраны сохраняют автоматический запуск.

Проверки
21 Node-сценарий завершён: прежние 18 и новые garden/look/soft-furnishings. Проверены исходные коллизии, материалы, геометрия и привязки модели, восемь помещений, размещение мебели, ресурсы сцены, режимы видимости, конечное сглаживание/разворот/reduced motion/reset. Тест подушек проверяет изменение только двух компонентов, неизменность остальной геометрии и исходных поз, размещение над старым препятствием дивана, раздельный текстиль и восстановление геометрии/материала после трёх стилей.
Браузерная приёмка: check-realism-browser.cjs; check-rooms-browser.cjs; check-materials.cjs; check-family-plan-browser.cjs. Реальная загрузка/повторное открытие, пять ширин, отсутствие GLB до открытия на телефоне, настоящий mouse drag и mobile touch, учебные схемы стен/кровли, реальные переходы и возвраты комнат, общий brief и clipboard write/readback. Проверка синхронной отмены ожидающего поворота при blur использует отдельно обозначенную контролируемую DOM-вставку после настоящего mouse down; не выдаётся за проверку ОС. Прежние скрипты включены как исходники и не все заново запускались.
Дополнительный capture-realism.cjs снимает окончательную сцену, проверяет применение новых подушек и актуальные мобильные параметры камеры. Кадры выполнены Chromium/SwiftShader; не Image Gen. Медиа — монтаж этих кадров, не непрерывная запись и не FPS устройства. Один кадр сравнения окна взят из реальной версии 25; остальные кадры относятся к версии 26.
Физический iPhone/Safari и производительность на телефоне не проверены. Расход памяти GPU на реальном устройстве не измерен; ограничение числа групп и корректный dispose не заменяют такой замер. До полной фотореалистичности ещё остаётся работа.
Нативный GLB, navigation.json, furniture-layout.json и сам walk-navigation.js совпадают с v25 (realism-model-integrity.json). В браузере временно дорабатываются только подушки; это не означает побайтовой неизменности их runtime-геометрии. Blender в этой версии не запускался.

Локальный запуск
npm install
npm run build
python3 -m http.server 8820 --bind 127.0.0.1
Открыть http://127.0.0.1:8820/index.html на том же компьютере.
Браузерные тесты используют ws из /workspace/stroyka-app/node_modules/ws; при переносе заменить собственной установкой ws. verify-browser-v26.py запускает заданные сценарии. Подробные логи и SHA256SUMS входят в ZIP.

Не подключены база расценок, реальные контакты и доставка обращения, каталог других проектов. Публичный интерактивный адрес пока отсутствует; raw HTML им не является. Рабочий сайт, main, production, службы и рабочая БД не менялись. Отдельная задача безопасной установки обновления приложения не закрывается этим прототипом.
